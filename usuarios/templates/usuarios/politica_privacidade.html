Política de Privacidade

Versão 1.0 | Última atualização: 30 de agosto de 2026

1. Introdução

O ERP Escola Profissionalizante ("Sistema") está comprometido com a proteção da privacidade e dos dados pessoais de seus usuários, em conformidade com a Lei Geral de Proteção de Dados (Lei nº 13.709/2018 - LGPD).

Esta Política de Privacidade descreve como coletamos, usamos, armazenamos e protegemos os dados pessoais dos usuários do Sistema.

2. Dados Coletados

Coletamos os seguintes dados pessoais:

  • Dados de identificação: nome, e-mail, CPF
  • Dados de contato: telefone, endereço
  • Dados funcionais: cargo, setor, jornada de trabalho
  • Dados de autenticação: e-mail, senha (hash), 2FA
  • Dados de acesso: IP, user-agent, logs de autenticação

3. Finalidade do Tratamento

Os dados pessoais são tratados para as seguintes finalidades:

  • Autenticação e controle de acesso ao Sistema
  • Gestão de usuários e permissões
  • Comunicação institucional
  • Segurança e auditoria
  • Cumprimento de obrigações legais

4. Base Legal

O tratamento de dados pessoais baseia-se em:

  • Execução de contrato (para funcionários e alunos)
  • Cumprimento de obrigação legal
  • Legítimo interesse (segurança e auditoria)
  • Consentimento (quando aplicável)

5. Compartilhamento de Dados

Os dados pessoais não são compartilhados com terceiros, exceto quando necessário para cumprimento de obrigações legais ou com prestadores de serviços que atuam em nome do Sistema (operadores de dados).

6. Retenção de Dados

Os dados pessoais são retidos pelo tempo necessário para:

  • Cumprir as finalidades para as quais foram coletados
  • Cumprir obrigações legais
  • Exercer direitos em processos judiciais ou administrativos

7. Direitos do Titular

Você tem direito a:

  • Confirmar a existência de tratamento de dados
  • Acessar seus dados pessoais
  • Corrigir dados incompletos, inexatos ou desatualizados
  • Solicitar a anonimização, bloqueio ou eliminação de dados desnecessários
  • Portabilidade dos dados
  • Revogar o consentimento

8. Segurança

Adotamos medidas técnicas e organizacionais para proteger os dados pessoais contra acesso não autorizado, destruição, perda, alteração ou comunicação indevida, incluindo:

  • Criptografia de senhas (Argon2)
  • Autenticação de dois fatores (2FA)
  • Logs de auditoria
  • Controle de acesso baseado em cargos

9. Cookies

Utilizamos cookies essenciais para o funcionamento do Sistema, como autenticação e segurança. Cookies de análise ou marketing só serão utilizados com seu consentimento explícito.

10. Contato

Para exercer seus direitos ou tirar dúvidas sobre esta Política de Privacidade, entre em contato com o encarregado de dados (DPO) através do e-mail: dpo@escolaprofissionalizante.com.br
